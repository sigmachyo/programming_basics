# Programming Basics

Базовый курс программирования. Практические задания с pr1 по pr21.

### Стек технологий
- **C++** (основной)
- **C**
- **CMake** / **Makefile**

### Смысл проекта
Закрепление фундаментальных навыков программирования: циклы, массивы, функции, указатели, динамическая память, работа с файлами.

### Для чего
- Начальный этап обучения программированию
- Подготовка к более сложным курсам (алгоритмы, ООП, структуры данных)
